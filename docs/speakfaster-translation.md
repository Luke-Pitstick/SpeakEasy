# SpeakFaster gaze editing translation

Reference: TeamGleason/SpeakFaster, revision `fb80a71fe846b03cad48654b76e4ff039aee475f`, MIT. Paths below are under `webui/src/app/`. This map is based on the TypeScript handlers, templates, and corresponding upstream tests, not just screenshots.

| Upstream behavior                                                                                                                                                                                                     | React translation and input destination                                                                                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `input-bar/input-bar.component.ts:onSpellButtonClicked` creates one letter chip per initial, retaining previously spelled words. `onChipClicked` changes the focused chip.                                            | Spell exposes abbreviation chips in the composition bar. Dwelling on a chip directs Dasher to that position; other positions remain intact. Switching positions retains the partial keyword.                                              |
| `input-bar-chip/input-bar-chip.component.ts:onMainButtonClicked` selects the chip text and focuses its input. `onChipTextChanged` records the entered text.                                                           | A selected chip is the visible input destination. Dasher supplies the replacement text directly; no hardware keyboard, caret placement, input focus, or drag selection is required.                                                       |
| `input-bar.component.ts:triggerAbbreviationExpansion` preserves the order of initials and spelled tokens, using `PREFIX` when incomplete keywords are enabled.                                                        | Prefix and full-word constraints remain distinct. Expansion uses the selected chip's text along with all other positions. Automatic requests happen after steering pauses, never during an active dwell or steering operation.            |
| `abbreviation/abbreviation.component.ts:onTextClicked` / `phraseToChips` opens candidate words for refinement. Its gaze setting uses two activations before opening. Selection/injection/speech are separate actions. | Each candidate has separate Edit and Use controls. Edit opens unaccepted phrase chips; Use explicitly accepts the phrase. Editing does not replace the accepted message. Separate labeled actions replace the implicit two-click gesture. |
| `input-bar.component.ts:onChipClicked` in word mode immediately sends `phraseWithMask`, `maskInitial`, and original words to FillMask.                                                                                | Selecting a phrase word immediately requests alternatives with the same first letter and preserves surrounding text. The selected chip can instead receive exact Dasher spelling.                                                         |
| `abbreviation-refinement.component.ts:onReplacementButtonClicked` substitutes the selected word and retains its punctuation.                                                                                          | Replacement updates the unaccepted editing phrase. Use phrase confirms it into the accepted message. Byte slices preserve punctuation and spacing without upstream punctuation normalization.                                             |
| `input-bar.component.ts:onAbortButtonClicked` restores the saved input text; refinement abort emits an empty phrase upstream.                                                                                         | Back restores the previous composition branch. Cancel word restores the original word. The upstream empty-string abort behavior is intentionally not copied.                                                                              |

Acceptance traces derive from upstream `input-bar.component.spec.ts`: `abc` with middle prefix `br` retains `a / br / c`; `i feel great` selecting `great` requests `i feel _` with initial `g`; manual replacement changes only the selected chip. The local tests also verify that a candidate can be corrected without accepting it and that the editing sequences work through dwell plus the Dasher output path, without input change or keyboard events.

The existing mouse adapter is a development stand-in for a tracker. Dwell is enabled by default and Start/Pause is a stable dwell target. No real eye tracker, research generation backend, or speech provider is implied. Four choices and the neutral stacked layout follow the SpeakEasy PRD rather than copying the upstream theme.

## Local verification

`tests/speakfaster-gaze.test.tsx` drives dwell timers and the actual Dasher frame loop with synthetic pointer samples. It covers initials → rejection → partial keyword → candidate editing → same-initial replacement → acceptance; exact spelling of “Zephyr” → cancel → retry → accept → undo; and an empty expansion → seventh-word paging → spelling and locking “George” → continuing entry. It never clicks a control, sends a key event, or fills a text field. The navigation helper uses engine intervals to aim synthetic samples, so these are functional checks, not a measure of human gaze usability.

`tests/composition.test.ts` checks the upstream constraint examples, punctuation preservation, stale results, and isolation of accepted text from candidate editing and deletion. The built Electron workspace and an isolated preview of its renderer were visually inspected; candidate editing, replacement suggestions, and exact-spelling controls fit at 1280 pixels wide. No live tracker or upstream generation service was exercised.
