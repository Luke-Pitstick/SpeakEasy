# Initials prediction: datasets and techniques

This records the data and methods used for SpeakEasy's offline next-word-initial PPM experiment. The predictor assigns probabilities to `a`–`z`; it does not expand initials into words. See the [experiment protocol](initials-ppm-plan.md) for the full selection and validation rules.

The initial audit counted **64,317 training initials** before production cleanup: 25,112 AAC and 39,205 Turk. These counts used a simpler audit tokenizer, so they are not final preprocessing totals. Under normalized text matching, 113 AAC development messages and 116 Turk development turns already appeared in training; report familiar and unfamiliar text separately.

These invented collections support a prototype experiment, not a claim about everyday AAC effectiveness.

## Techniques

1. **Reproducible preprocessing.** Pin source bytes by hash and preserve original splits. Normalize with NFKC, lowercase, and straight apostrophes. Keep contractions as one word (`don't` → `d`, `I'll` → `i`), and split hyphenated words. Unsupported digit-containing tokens and unsupported non-ASCII initials reset context. Reset history at every message/turn boundary and use a context-only start marker, preventing artificial sequences between messages.
2. **Bounded PPM with backoff.** Reuse the existing Apache-2.0 jslm-derived algorithm, shared through the pure [initials model](../src/shared/initialsPpm.ts). Compare history caps of 2, 4, 6, 8, and 10; AAC-only, Turk-only, and equal source probability mixtures; and uniform mixtures of 0.05, 0.10, and 0.20 (45 candidates). The recorded estimator uses alpha 0.49, beta 0.77, and no exclusion. Apply `p(letter) = (1 - epsilon) * p_ppm(letter) + epsilon / 26` once so every letter retains positive probability. Train offline and export a frozen asset.
3. **Development selection with repetition controls.** Compare against uniform and tuned learned unigram baselines. Select on the equally weighted AAC/Turk unseen-full-text loss, with training membership defined against both training sources for all candidates. Report full splits and unseen-initial-string subsets too. Within 0.01 bits/initial of the minimum, prefer shorter history, then a single source, then a larger floor, then AAC.
4. **Probability evaluation and uncertainty.** Measure mean `-log2(p_actual)` in bits per initial, top-1/3/5 accuracy, intended-letter probability tails, and the fraction below 1%. Break results down by source, novelty, letter, position, and the first 24 initials supported by the UI. Use 2,000 fixed-seed paired bootstrap resamples, grouped by Turk dialogue and AAC/COMM2 message; unavailable worker/scenario metadata limits the uncertainty estimates.
5. **Freeze before final evaluation.** Record the selected model and protocol hashes before scoring original test splits and COMM2. Do not refit on development data or update during evaluation. Any later tuning informed by COMM2 makes it a regression benchmark and requires new untouched data for another unseen-test claim.
6. **Validate navigation separately.** Positive letter probabilities and lower prediction loss do not establish usable regions or faster communication. Check lookup latency, rare-letter reachability, reversal, correction, and stable active regions, then compare completion times on the same gaze tracker with fixed phrase generation.

Long histories have little repeated support: the initial audit found only 35 distinct six-initial histories occurring at least three times before another initial, and only one eight-initial history. Backoff and the preference for shorter competitive models address this sparsity.

## Saved offline run

The existing [results report](../artifacts/initials-ppm/f70020135ab3a402/report.md) records run `f70020135ab3a402`, using protocol `initials-ppm-offline-v1` and tokenizer `english-initials-v1`. It selected **history 2, equal AAC/Turk probability weights, and a 0.10 uniform mixture**, and reports passing development and final offline gates. Balanced unseen-text development improvement over unigram was 0.231 bits/initial (95% interval 0.207–0.253); COMM2 unseen-text improvement was 0.271 (0.250–0.291).

Model SHA-256: `2780b90e230892ba92fd8c2c16053c8d61558595a1a92b2247b48ee02d5171ba`.

These are results from the saved report, not a new rerun. Its directory contains acquisition manifests, preprocessing summaries, candidate metrics, the frozen model, and final scores. The offline tools live in [scripts/initials-ppm](../scripts/initials-ppm/). The original plan describes the earlier design-stage status; the saved report records the subsequent offline run. Dasher integration, practical engine reachability, and gaze trials remain outstanding in that report, so no faster-communication claim is established.
