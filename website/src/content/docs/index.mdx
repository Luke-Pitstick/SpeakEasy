SpeakEasy is a free and open source desktop app for writing and speaking with your eyes. You enter the first letter of each word, review a suggested phrase, and choose when to say it out loud.

## Highlights

- Steer with a mouse, webcam gaze, a head pointer, or an eye tracker that moves the desktop pointer.
- Select any control by dwelling on it, with an adjustable dwell time.
- Write in exact spelling mode with no account and no cloud service.
- Keep control of the wording. A suggestion changes nothing until you select it, and nothing is spoken until you select **Speak**.
- Keep your camera private. Webcam frames are processed on your computer and are never saved or sent.
- Turn on cloud phrase suggestions and cloud speech separately, only if you want them. See [What leaves your device](privacy/data/).
- Run it on macOS, Windows, and Linux.

## Installation

SpeakEasy is in development. [Download the latest test installer](getting-started/install/) for macOS, Windows, or Linux, or [build it from source](getting-started/install/#build-from-source) with Git and Node.js 24. Then follow the [Quick start](getting-started/quick-start/) to write your first message.

## Ways to point

| Input | Status | Setup |
| --- | --- | --- |
| Mouse or trackpad | Supported | Choose **Mouse** in **Menu → Settings → General**. |
| Webcam gaze or head pointer | In testing | Choose **Eye tracker (webcam)** or **Head pointer (webcam)**. Webcam gaze has been exercised with real calibration data. |
| Dedicated eye tracker | Unverified | Leave **Input** on **Mouse** and let the tracker software move the desktop pointer. Model-specific compatibility has not been tested yet. |

[Input setup](getting-started/input-setup/) walks through each one. If you test a tracker, a [compatibility report](https://github.com/Luke-Pitstick/SpeakEasy/issues/new?template=tracker-compatibility.md) is the most useful contribution you can make.
